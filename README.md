# China–EU Cross-Border Data Transfer Reference

A working reference on cross-border data transfer between mainland China and the EU/EEA.

Its value is not comprehensiveness — it is verification discipline:

- Every legal statement carries its instrument, article, and the date the content was verified.
- Statutory requirements, interpretive positions, and unsettled questions are labelled separately and never blended.
- Where a rule is dynamic — negative lists, guidance editions, certification standards — the reference says where to retrieve the current version rather than stating a value that will go stale.

- [`china/routes.md`](china/routes.md) — PRC export routes for personal information: the instruments in force, order of analysis, exemptions, threshold routing, obligations that survive every exemption, validity and re-filing.

## Labels

`[Statutory]` the instrument says this · `[Interpretive]` a defensible reading or a regulator's published guidance, not statutory text · `[Unsettled]` genuinely open · `[Dynamic — retrieve current version]` changes without any instrument being amended · `[To be verified]` not confirmed against a retrieved source

## Note

Research material, not legal advice. Each file carries a verification date; content should be rechecked against primary sources before being relied on.
